# Pozele Verei, decupate

Cele 15 fotografii editate din ședința foto (folderul „obrabotannye”), cu fundalul scos.
Sunt WebP cu transparență, la 3000px înălțime, bune pentru Figma, Stories, prezentări sau alte pagini.

Fundalul a fost scos cu motorul de decupare din macOS (Vision). Marginile au fost rafinate cu
closed-form matting, pentru firele de păr, și curățate de culoarea fundalului de studio, ca să
nu rămână contur pe fundaluri colorate.
